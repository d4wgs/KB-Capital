# KB Capital workspace style guide

The workspace organizes financial monitoring and research around a fixed navigation rail and a single content column. Each page starts with a category breadcrumb and a compact title. The sidebar uses the static Gaussian symbol. About us retains the animated Gaussian wordmark.

| Element | Convention |
| --- | --- |
| Surfaces | Continuous white, thin #E3E7ED rules, minimal corner rounding |
| Hierarchy | Inter 600 headings, numbered sections, Inter 400 body copy |
| Data | IBM Plex Mono, tabular numerals, right-aligned amounts where columns permit |
| Color | #101114 primary text, #64748B secondary text, #244FC4 active controls, #EDF1FA selections |
| Financial states | Signed figures and explicit labels alongside green gains and red losses |
| Navigation | Fund, Trading, Research, Risk and Operations appear as authorized pages become available |
| Responsive shell | Collapsible desktop rail, mobile navigation toggle, keyboard-accessible global page search |
| Charts and tables | Shared grid, compact legends, visible units and time ranges, expandable trade details |

The source of truth for tokens is [tokens.css](workspace/templates/tokens.css). The [component library](workspace/templates/components.html) and development showcase demonstrate the patterns. Preserve the distinction between hypothetical targets and observed returns, and keep the original risk disclosures with the relevant figures.
